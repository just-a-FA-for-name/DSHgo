# DSHgo V1.3 · 连接恢复与 WebView 兼容性修复

**大家反馈的问题我都有在看，没有装死。** 这次针对 [issue #5：页面一直加载](https://github.com/just-a-FA-for-name/DSHgo/issues/5)、[issue #6：连接失败](https://github.com/just-a-FA-for-name/DSHgo/issues/6)，结合实际诊断日志做了集中修复。感谢提供日志和复现信息的朋友。

## 本次修复

- **复杂网络下反复断连、恢复过程被打断**：只在实际承载网络、DNS 或验证状态变化时处理网络切换，避免后台蜂窝网络回调误触发重连；健康连接不再被简单网络提示强制打断，同一故障周期减少重复恢复事件。
- **#5 页面卡在加载、脚本与插件无法正常启动**：电脑桥接不再默认强加 COOP/COEP，保留上游策略；提前补齐缺失的 Promise.withResolvers / AbortSignal.any，手机使用真实 WebView UA，增加脚本、插件资源和页面启动阶段的诊断分类。
- **#6 部分设备和内网地址连接失败**：隧道 socket 绑定改用公开 Android API，替代隐藏字段反射；允许显式配置的 tailnet、私有局域网 HTTP 地址，并检查地址范围。公网地址仍要求 HTTPS，不自动降级，不绕过 HTTPS 证书或 SNI 校验。
- **电脑插件启动与重试**：自动查找桌面版自带的 dsh CLI，减少 PATH 不完整造成的启动失败；Tailscale Serve 失败采用退避，避免反复等待同一请求。
- **连接状态误报**：认证失败、限流和服务器错误独立显示，HTTP 业务错误不再直接视为断网。
- **诊断更准确**：正确说明内置隧道，删除误导性的独立 Tailscale 安装提示及不存在的脚本提示；增加实际 MagicDNS 配置、socket 绑定、实际网络变更和页面资源失败信号。

## 两端都要升级

1. 手机覆盖安装 **DSHgo-v1.3.apk**，同签名升级保留原有数据和设置。
2. 电脑下载 **DSHgo-pc-plugin-v1.3.zip** 并完整解压，进入 `pc-plugin`，运行 `install.bat` 更新现有插件。
3. 等电脑任务结束后，退出并重新打开 dsh 桌面版。

这是现有 dsh-phone-remote 的升级，无须另装一套远程工具或重装 Tailscale。只更新 APK，无法获得电脑桥接里的页面启动兼容修复与插件重试策略。

## 测试情况与后续反馈

39 项隔离回归通过。一加 Android 16 / WebView 156 上验证了实际 socket 绑定、压缩页面及同步/模块脚本加载、GET 连接 reset 后恢复、POST 到达隔离上游后断开不由应用/桥接重复提交，以及 WebSocket 握手。正常网络前台观察 138 秒没有新增异常或重连状态。

**#5/#6 已做针对性修复，但报告者的 WebView 150、Android 13 / WebView 116 和真实复杂运营商 5G 环境仍待复测。** 目前不声称已确认所有故障的唯一根因，也不将发布版本等同于所有机型均已解决。详细测试范围见 [V1.3 验收记录](V1.3验收记录.md)。

仍有问题请在设置 → 故障排查 → 导出诊断包，附上出现问题的时间、手机系统/WebView 版本及网络情况。无需 root；日志只保存有界数字状态分类，不记录聊天、连接地址、Cookie 或 Token，不自动上传。

V1.2 已有的文件分块续传、应用专用隧道、可切换大肥鱼主题及开屏动画继续保留。
